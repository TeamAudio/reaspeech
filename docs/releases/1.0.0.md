# ReaSpeech 1.0.0

Speech-to-text inside REAPER, now without Docker! ReaSpeech 1.0 uses ReaSpeech
Lib for transcription and installs through ReaPack. Recognition runs in the
background with progress reporting and cancellation.

## Upgrading from 0.7.x and other Docker-based versions

1. Close the old ReaSpeech window. Add the Team Audio repository to ReaPack:

   ```text
   https://github.com/TeamAudio/reascripts/raw/main/index.xml
   ```

2. Install **ReaSpeech**, one **ReaSpeech Lib** backend, and **ReaImGui** 0.10
   or newer. Restart REAPER to load the extension.
3. Run the ReaPack-installed ReaSpeech script from REAPER's Actions window.
   Update any keyboard shortcuts and toolbar buttons to use this action.
   Your old downloaded script is a separate copy and still expects the Docker
   web service; installing through ReaPack does not update that copy.
4. Select a media item and click **Transcribe Selected Items** to check the
   new setup. Once it works, stop your old ReaSpeech Docker container and
   disable any automatic startup for it. You can then remove the old script's
   action after updating your shortcuts.

Docker and the local web server are no longer required for ReaSpeech. There
is no need to uninstall Docker or remove containers used by other tools.

## Need the legacy version?

The older images remain available on
[Docker Hub](https://hub.docker.com/r/techaudiodoc/reaspeech), with setup
instructions in the
[0.7.3 documentation](https://github.com/TeamAudio/reaspeech/tree/v0.7.3/docs).
We will continue hosting these images for a limited time, so please plan to
move to the new version.
